# KWin 6.7.5 VirtualDesktopManager desktop signatures

The [v6.7.5 interface XML](https://github.com/KDE/kwin/blob/v6.7.5/src/org.kde.KWin.VirtualDesktopManager.xml) declares `org.kde.KWin.VirtualDesktopManager.desktops` as `a(iss)`. The [same tag's struct declaration](https://github.com/KDE/kwin/blob/v6.7.5/src/virtualdesktopsdbustypes.h) defines `DBusDesktopDataStruct` in order as `uint position`, `QString id`, `QString name`. Its [marshaller](https://github.com/KDE/kwin/blob/v6.7.5/src/virtualdesktopsdbustypes.cpp) writes those fields in that order inside a structure and an array. The source-defined runtime wire signature is therefore `a(uss)`. The local KWin 6.7.5 read-only property reply observed in Batch 004B was `a(uss)`.

This is an exact-version metadata/runtime discrepancy. For **exactly KWin 6.7.5** and **exactly this `desktops` property**, the pilot requires introspection to advertise `a(iss)` and the live property reply to have type `a(uss)`. It requires the remaining reviewed method/property names, kinds, and signatures to match exactly: `createDesktop(us)`, `setDesktopName(ss)`, and `removeDesktop(s)` have no return value; `count` and `rows` are `u`; `current` is `s`. Desktop positions must be non-negative integers in exact order `0..count-1`, with `count` equal to the number of desktops and string IDs/names. The current ID must be among the desktops.

Any other KWin version, changed declared signature, changed runtime signature, missing or incompatible extra member, or malformed payload fails closed. This rule does not accept either signature opportunistically and does not extend to another KWin version or interface.
