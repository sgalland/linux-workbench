# Machine profiles

This directory holds machine-specific profiles, hardware observations, and local constraints. Keep those details separate from machine-independent workstation intent in `spec/`.

The first profile will eventually cover the HP Envy laptop. Its problematic Bang & Olufsen internal-speaker configuration is known but explicitly deferred: do not diagnose or change audio configuration as part of this initial scaffold.

The local Git repository convention on this CachyOS installation is `~/Projects`. Follow [`../AGENTS.md`](../AGENTS.md) for safety boundaries.
